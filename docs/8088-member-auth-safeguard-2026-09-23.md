# 8088 会员接口临时保护（2026-09-23）

## 原因与现状

- 阿里云服务器公网 `:8088` 运行独立 H5，**不是** 80/443 的 WordPress 正式官网。旧 H5 发布包会使用固定的开发模拟身份，旧 API 也接受这类身份；不同访客可能进入同一测试会员会话。
- 已在 `:8088` 的 Nginx 代理临时拒绝 `/api/auth/wx-login`、`/api/auth/bind-mobile` 和 `/api/member/`。因此该入口的会员登录、资料、地址及历史报价暂不可用；首页、产品目录和正式 WordPress 官网仍可访问。
- 服务器的 API 和 H5 进程**尚未**发布本地认证修复。不要仅因 Git 提交或本地测试通过就移除上述代理限制。
- 对共享测试身份做了只读计数检查：账号存在，但目前没有会员档案、地址或报价。未查看个人字段；这不能证明历史上没有其他访问。

## 已完成的保护与验证

- 现行代理配置从服务器原文件同步并校验后编辑，保存于 `deploy/nas/nginx-live-20260923.conf`；原配置备份在服务器 `/root/nginx-8088-before-safeguard-20260923.conf`，候选文件在 `/root/nginx-8088-safeguard-candidate-20260923.conf`。
- 实际代理挂载路径为 `/opt/yinshua/current/nginx.conf`。更新前后均核对文件内容；Nginx 在同一 Podman 网络及运行容器内通过语法检查，随后平滑重载，未重启数据库、API 或 WordPress。
- 公网复核：`:8088/` 与 `/api/catalog/categories` 返回 200；受保护的登录、手机号绑定、会员接口返回 403；正式 HTTPS 官网返回 200。第一次重载因 Podman 内部 DNS 临时解析失败未生效，受控重试后成功；再次验证才认定保护生效。
- 本地源码已将模拟登录改为默认禁用（仅非生产环境显式开关可启用）、旧模拟 token 默认拒绝、手机号绑定改为当前会员授权；H5 取消自动模拟登录和未登录资料表单。本机 API 类型检查、38 个单元测试、9 个独立库集成测试及 H5 构建通过。**以上本地代码尚未在服务器运行。**

## 恢复会员入口前

1. 明确真实会员登录方式并配置正式微信参数；为 H5 提供真实登录入口，不能再使用固定开发身份。
2. 审核并发布已收紧的 API/H5 源码，验证模拟登录、旧模拟 token 和越权手机号绑定均被拒绝，同时真实登录与本人资料访问正常。
3. 当前 `qddflc-api` 容器启动命令包含依赖安装、`prisma:push`、可能的 `db:seed` 和构建。**不要直接重启该容器**；先把部署流程改为不会对业务库重复建表/播种，并准备备份与回退。
4. 发布及验收完成后，才从 8088 配置移除三个临时拦截并平滑重载，重新验证公开页面、产品、登录和会员接口。Podman 短域名在运行容器中曾无法稳定通过 Nginx 重新解析；当前配置使用 `qddflc-api.dns.podman`，重载前必须在运行容器内执行 `nginx -t`，失败时不要重载。

不应通过恢复旧代理配置来提前开放会员接口。WordPress 官网与此 8088 保护互相独立。
